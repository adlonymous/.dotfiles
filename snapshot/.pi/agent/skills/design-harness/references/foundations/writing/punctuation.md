## Rules

**Double-hyphen for dashes**: Type `--` instead of em-dash `—`. No spaces around it.
Example: "Design harnesses--a new concept--are powerful."

**Straight quotes**: Use `"` and `'`, not curly quotes `""` or `''`.

**No ellipses in UI**: Avoid `...` in interface text. Use complete sentences or truncate cleanly.

**Oxford comma**: Use serial comma in lists.
Example: "colors, spacing, and motion"

**Periods in UI**: Omit periods in single-sentence labels/buttons. Use periods in multi-sentence help text.

**Colons for lists**: Introduce lists with a colon when the intro is a complete clause.
Example: "Three fonts: Inter Display, Shinka, Kult Luxury."

**No exclamation marks**: Avoid in UI text and articles. Let the content speak without hype.

## Rationale

- Double-hyphen: Plain, typeable, intentional
- Straight quotes: ASCII simplicity, code aesthetic
- No ellipses: Decisiveness over vagueness
- Oxford comma: Clarity
- No exclamation marks: Calm, confident tone
