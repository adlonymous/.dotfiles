`--mono: "ABC Favorit Mono Trial", "SF Mono", ui-monospace, Menlo, monospace`, loaded with `font-display: optional` from `fonts/ABCFavoritMono-Regular-Trial.otf`.

Where it is used:

- the Experiments glyph atlas ([glyph matrix](../../components/patterns/glyph-matrix.md))
- the year on a Library spine
- the time on each Settings › Sound card

It is a commercial typeface from Dinamo (ABC), here in its trial cut. **The font file is not in this harness and must not be committed.** A rebuild uses the fallbacks (SF Mono, ui-monospace, Menlo) or a licensed copy supplied by the owner.

The UI face is Inter Display (not Favorit). Favorit Mono is only the mono face.
