**⚠️ COMMERCIAL LICENSE REQUIRED — NOT INCLUDED IN THIS HARNESS**

Shinka is a commercial serif typeface by Aeiou Tools used for body text on saleh.digital.

## License

**You must purchase your own license** to use Shinka. It is NOT included in this harness or repository.

**Source:** https://aeiou.tools/purchase/shinka

## Fallback

If you don't have a Shinka license, use:

```css
font-family: Georgia, serif;
```

## Weights Used

- Regular 400
- Italic 400

## Specimen

- Body text: 16px/20.8px
- Dialog descriptions: 14px/18px
- Filter: `url(#ink-body)` for texture

## Metric Overrides

```css
@font-face {
  font-family: Shinka;
  size-adjust: 100%;
  ascent-override: 91%;
  descent-override: 25%;
  line-gap-override: 0%;
}
```

## Do NOT Bundle

- No `.woff`, `.woff2`, `.otf`, or `.ttf` files
- No base64 font data
- Owner supplies font files separately
