## Principle

Every design decision--color, spacing, motion, texture--must serve a functional purpose. Beauty emerges from precision and clarity, not from applied ornament.

## In Practice

**Prefer functional detail**:
- Ink filters that improve readability, not just aesthetics
- Spacing that creates hierarchy, not arbitrary gaps
- Motion that communicates state change, not decoration

**Avoid decorative additions**:
- Gradients or patterns with no meaning
- Animations that distract rather than inform
- Texture applied for "richness" without purpose

## Examples

**Good**:
- Ink filter on body text improves perceived sharpness and warmth
- 16px image border-radius suggests tactility (rounded physical object)
- Switch toggle animation shows state transition clearly

**Bad**:
- Animated background pattern that draws attention away from content
- Gradient on button for "premium feel" with no functional reason
- Excessive drop shadows for depth without hierarchy

## Questions to Ask

1. What function does this detail serve?
2. Does it help the user understand, navigate, or read?
3. Could I remove it and lose no utility?

If the answer to #3 is "yes," remove it.
