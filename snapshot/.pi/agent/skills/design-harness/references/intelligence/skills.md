# Skills Overview

Skills are procedural guides that agents follow to complete specific tasks correctly and consistently.

## Available Skills

**SDF Rendering**: Signed-distance field techniques for smooth, scalable text and graphics.

**CMS Records**: How to structure and manage content records in the CMS.

**Screenshot Review**: Visual regression testing and comparison workflow.

**Figma Import**: Pull designs and specs from Figma files into harness and codebase.

**Generative Sound**: Implement subtle sound feedback for UI interactions.

**Catalogue Lookup**: Query the design harness for reference to ensure consistency.

**Theme Tokens**: How to apply and document design tokens (CSS custom properties).

## Skill Structure

Each skill defines:
1. **Purpose**: What the skill accomplishes
2. **Steps**: Ordered procedure to follow
3. **Examples**: Code snippets or commands
4. **Related**: Links to relevant tools, packages, or memories

## Usage

Agents invoke skills when:
- Starting unfamiliar tasks ("How do I import from Figma?")
- Ensuring consistency ("What's the CMS record structure?")
- Following best practices ("How do I test visual regressions?")

## Maintenance

Skills evolve with the site. Update skills when procedures change or new techniques emerge.
