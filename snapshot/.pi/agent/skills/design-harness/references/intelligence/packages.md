# Packages Overview

External libraries, APIs, and tools used in Saleh Digital's build, rendering, and content management.

## Packages

**Admin Kit**: Internal admin interface components and utilities.

**Amicons**: Commercial icon set (license required). See repo README for license notice.

**Inter Display**: Open-source UI typeface (SIL OFL 1.1).

**Kult Luxury**: Commercial display typeface for wordmark (license required).

**Shinka**: Commercial serif typeface for body text (license required).

**Open Library**: Public API for book metadata and covers.

**Python Standard Library**: Built-in Python modules for build scripts and tooling.

**sips**: macOS scriptable image processing system.

**Three.js**: WebGL library for 3D graphics and shaders (experimental).

**TipTap**: Headless rich-text editor for CMS.

## Commercial Assets

**Shinka**, **Kult Luxury**, and **Amicons** are commercially licensed. Others using this harness must purchase their own licenses from the respective vendors. See repo README and `LICENSE-CONTENT` for full notices.
